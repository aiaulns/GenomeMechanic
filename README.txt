Запуск: откройте index.html в браузере или разместите содержимое папки в корне GitHub Pages.

Языки интерфейса: қазақша (ҚАЗ), русский (РУС), English (ENG). Переключатель — в правом верхнем углу.
Выбор сохраняется в браузере; при первом открытии язык определяется по настройкам браузера.
Все тексты хранятся в assets/i18n.js — чтобы исправить перевод или добавить язык, редактируйте только этот файл.

Состав: обзор (с блоком авторства), просмотр экспериментальных структур PDB через 3Dmol.js, учебная анимация BER, виртуальный практикум, теория по основным механизмам репарации ДНК, раздел заболеваний человека и тест.

Переключение темы: «Авто» (системная тема устройства), «Светлая», «Тёмная». Выбор сохраняется в браузере.

Для загрузки экспериментальных 3D-структур требуется подключение к интернету. Без него доступна учебная схематическая модель.

Файлы: index.html, assets/app.js (логика), assets/i18n.js (переводы), assets/style.css (оформление).
